# 路线图（Roadmap）

> 目标：在「永久免费、零遥测、离线优先」的前提下，把 SecurePass 从「个人自用工具」
> 做到「陌生人敢装、安全工作者敢签字、日常能替代商业管理器」。
>
> 版本号是**范围**而不是**日期承诺**：每个版本做完并通过门禁才发布，更新节奏可能变慢，
> 但不跳票、不半成品（见 `docs/MAINTENANCE.zh-CN.md`）。

## v0.3 — 安全可签字

| 项目            | 说明                                                                      |
| --------------- | ------------------------------------------------------------------------- |
| 威胁模型        | `docs/THREAT-MODEL.zh-CN.md`：资产、攻击面、信任边界、已接受的残余风险    |
| KDF 提升        | 默认 `256 MiB / t=4`，并提供密钥迁移（旧库首次解锁后自动重包裹 DEK）      |
| 主密码强度      | 复用强度/字典检查（对齐 zxcvbn 思路），创建时给出可读建议                 |
| 恢复码          | 随机生成的 24 词/160-bit 恢复码，用于主密码遗忘时恢复（本地保存，不联网） |
| 解锁退避        | 连续失败指数退避（1s→30s 上限），KDF 仍是主要成本                         |
| 属性测试 + fuzz | 密码库解析/解密路径的属性测试与 ≥24 小时 fuzz 语料                        |

## v0.4 — 日常可用

| 项目       | 说明                                                                                 |
| ---------- | ------------------------------------------------------------------------------------ |
| 导入       | CSV（通用格式）、Bitwarden JSON、KDBX 只读；导入前预览与冲突处理，导入后清空中间文件 |

## v1.0 — 商业级

- 三平台验收（Windows 已实测；macOS 未签名说明；Linux AppImage/deb 冒烟）；
- 可复现构建（固定工具链与依赖锁，产物哈希可复算）；
- 兼容性矩阵（Windows 10/11、macOS 13+、主流 Linux 发行版）；
- 安全公告流程（Advisories + `SECURITY.md` 升级路径）；
- 用户手册补全（导入、TOTP、恢复码、健康检查）。

## 明确不做

- ❌ 云端同步服务、账号体系、远程注册（只保留未来可选的第三方同步方案调研）；
- ❌ 团队共享、组织权限、审计后台；
- ❌ 自动修改网站密码、浏览器云同步注入；
- ❌ 任何形式的遥测、使用统计、广告、付费墙；
- ❌ 付费签名证书（Azure Trusted Signing）与付费第三方审计——免费方案（SignPath、社区 review）优先。

## 版本与数据兼容

- 新增字段必须向后兼容：旧库解锁时由 `validatePayload` / `repairItems` / `normalizeSettings` 自动修补；
- 破坏性格式变更必须递增 `formatVersion` 并补迁移测试；
- 每个版本发布前跑：`format:check` → `typecheck` → `lint` → `test:coverage` → `build` → `e2e-smoke`。
