# SecurePass 用户手册

本手册面向日常使用者，介绍怎么安装、第一次怎么用、以及忘记密码这类情况会怎样。
想了解实现细节请看 [ARCHITECTURE.md](ARCHITECTURE.md) 与根目录的 [SECURITY.md](../SECURITY.md)。

---

## 1. 安装与启动

SecurePass 完全离线运行，不需要账号，也不会联网。

| 方式       | 做法                                                     | 适用场景                         |
| ---------- | -------------------------------------------------------- | -------------------------------- |
| 安装包     | 双击 `SecurePass-<版本>-win-x64.exe`，按向导选择安装目录 | 日常使用（开始菜单里有快捷方式） |
| 免安装目录 | 解压后直接双击 `SecurePass.exe`                          | 放在 U 盘或临时机器上使用        |
| 从源码运行 | `npm install` → `npm run start`                          | 开发或自行构建                   |

> 安装包没有代码签名，第一次运行时 Windows SmartScreen 可能提示「Windows 已保护你的电脑」，
> 点「更多信息 → 仍要运行」即可。校验文件完整性请对照发布页的 `SHA256SUMS.txt`。

关闭窗口后程序退出；重新打开会恢复到上次的窗口大小与位置。

## 2. 第一次使用：创建密码库

1. 启动后直接进入工作台，上半部分是密码生成器，下半部分是密码库。
2. 密码库初始是锁定的，点「创建密码库」。
3. 设置主密码（至少 8 位，建议 12 位以上的一句话），点创建后会再确认一次：
   **主密码无法找回、无法重置**，请先记到安全的地方。
4. 创建成功后自动解锁，可以开始添加记录了。

**主密码就是唯一的钥匙。** 忘记了没有任何后门可以恢复 —— 这是设计上的取舍，不是缺陷。
建议：把主密码写在一张纸上锁进抽屉，或存进另一个你信任的密码管理器。

---

## 3. 生成密码

- 拖动滑条或用数字框设置长度（8–20 位）。
- 勾选需要的字符类型：大写字母、小写字母、数字、特殊符号。
- 「排除易混淆字符」会去掉 `l`/`1`/`I`、`O`/`0` 这类肉眼难分的字符，适合需要手抄的场景。
- 生成结果下方显示强度条、等级和估算熵值；如果配置不够安全（太短、类型太单一），
  会直接给出建议。
- 「复制」会把密码放进剪贴板，并在设定的时间后自动清空（默认 30 秒，可在设置里调整）。
- 「保存」把当前密码存进密码库：如果密码库还锁着，会先弹窗要求解锁。

---

## 4. 管理记录

| 操作     | 说明                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| 新增     | 点右上角「新增记录」或按 `Ctrl/Cmd + N`                                              |
| 搜索     | 按 `Ctrl/Cmd + F` 跳到搜索框；支持名称、账号、网址、分类与标签，**不搜索密码与备注** |
| 分类筛选 | 搜索框右侧下拉框，按分类过滤                                                         |
| 查看     | 眼睛图标打开详情；密码默认隐藏，点击可临时显示                                       |
| 复制     | 账号、密码各有独立复制按钮，复制密码同样会定时清理剪贴板                             |
| 编辑     | 铅笔图标；关闭未保存的编辑会先确认，避免误丢输入                                     |
| 收藏     | 星标图标，收藏的记录列表里有标记                                                     |
| 删除     | 垃圾桶图标并确认；删除后 8 秒内可在右下角提示里点「撤销」恢复                        |

搜索与筛选只在内存里对已解锁的数据做匹配，不会写回磁盘；备注字段不参与搜索，
是为了避免明文备注在渲染层常驻。

## 5. 锁定与解锁

- 点「锁定密码库」或按 `Ctrl/Cmd + L` 立即锁定。
- 无操作达到设定时长（默认 5 分钟）会自动锁定；切到别的窗口、长时间发呆、系统锁屏或休眠
  同样会触发锁定。真正在操作 SecurePass 时不会误锁。
- 锁定后：界面上的记录、搜索结果、打开的弹窗全部清空，任何访问都返回「密码库已锁定」。
- 解锁只需输入主密码；连续猜错没有次数限制，但每次尝试都要跑一遍 Argon2id，很慢。

生成器的倒计时提示会显示「N 分钟后自动锁定」，方便你知道还剩多少时间。

## 6. 设置

设置入口在标题栏左上角的齿轮图标。

- **自动锁定**：1 / 5 / 10 / 15 / 30 / 60 分钟（无操作时长，同时参考系统空闲与窗口焦点）。
- **复制后清理剪贴板**：5 / 15 / 30 / 60 / 120 秒。只有剪贴板内容仍是本次复制的内容时才会清空，
  中间你复制了别的东西不会被误删。
- **主题**：浅色 / 深色 / 跟随系统。
- **强调色**：6 套预设，会影响按钮、选中态与标题栏。
- **界面布局**：生成器在上 / 在左 / 在右。
- **语言**：简体中文 / English（切换立即生效，含日期格式）。
- **修改主密码**：输入当前主密码与新主密码。修改后**旧备份仍用旧主密码解锁**，
  建议改完重新导出一份备份。旧备份不会自动删除。
- **关于**：版本号、Electron/Chromium/Node 版本、数据目录位置与「打开目录」按钮。

锁定状态下，与密码库相关的设置会显示为不可编辑，解锁后才能修改；
主题、语言、强调色、布局这类界面偏好随时可改。

## 7. 备份与恢复

- **导出备份**：选择保存位置，得到一个加密的 `.securepass` 文件。它仍然用当前主密码保护，
  所以可以放心放到网盘；但请不要和主密码放在一起。
- **从备份恢复**：选择备份文件并输入该备份的主密码。恢复会**覆盖当前整个密码库**，
  所以会先弹确认框；覆盖前程序会把当前库另存为 `vault.securepass.pre-restore-<时间>.bak`。
- 恢复后密码库会重新生成内部标识与盐值，部分文件层面的关联（例如云盘去重）会变化，
  但记录内容与导入时完全一致。
- 错误的备份文件或错误的主密码不会改动现有密码库。

建议：每次批量改动记录、以及修改主密码之前，都导出一份备份。

## 8. 数据放在哪里

所有数据都在 Electron 的用户数据目录里，卸载程序不会删除它们：

| 系统    | 路径                                        |
| ------- | ------------------------------------------- |
| Windows | `%APPDATA%\SecurePass\`                     |
| macOS   | `~/Library/Application Support/SecurePass/` |
| Linux   | `~/.config/SecurePass/`                     |

| 文件                                | 内容                                                           |
| ----------------------------------- | -------------------------------------------------------------- |
| `vault.securepass`                  | 加密的密码库（记录、分类、标签、自动锁定与剪贴板设置）         |
| `vault.securepass.bak`              | 上一次写入前的加密副本，用于磁盘异常时回滚                     |
| `vault.securepass.<pid>.<时间>.tmp` | 写入过程中的临时文件，正常情况下不会残留                       |
| `vault.lock`                        | 单实例写锁，带有进程心跳                                       |
| `ui-preferences.json`               | **明文**，只存主题、语言、强调色与生成器位置，不含任何账号密码 |
| `window-state.json`                 | **明文**，只存窗口大小与位置                                   |

备份这些文件就等于备份了应用状态；但只有 `vault.securepass` 需要主密码才能解读。

## 9. 常见问题

**忘记主密码了怎么办？**
无法找回。唯一能做的是删掉（或改名）`vault.securepass` 重新创建密码库，旧数据将无法解密。

**提示「密码库正被另一个进程使用」？**
同一个密码库只允许一个 SecurePass 实例写入。请先关闭其他窗口；
如果确认没有其他实例（例如上次异常退出），最多等待 60 秒，锁的心跳过期后会自动回收。

**改完主密码后，之前的备份打不开了？**
不是打不开，而是旧备份仍用**旧主密码**。程序不会自动用新密码重新加密历史备份。

**能导入 Chrome / 1Password 的密码吗？**
当前版本不提供批量导入导出，记录需要手动添加（这是为降低明文泄露面而做的取舍）。

**双击 exe 没反应？**
检查是否已经有一个实例在运行（单实例限制会直接退出新实例）；
另外某些自动化环境会用「以 Node 模式运行 Electron」的方式启动，这会让程序当成 Node 直接退出。

**数据会不会上传？**
不会。程序没有网络请求代码，也不采集任何统计信息。

## 10. 卸载

- 用安装包安装的：在「设置 → 应用」里卸载，或使用安装目录下的卸载程序。
- 卸载**默认保留** `%APPDATA%\SecurePass` 里的数据；如果要彻底清除，卸载后手动删除该目录
  （删除后数据无法恢复，请先导出备份）。
