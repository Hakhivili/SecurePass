# 隐私说明（Privacy）

> 适用版本：SecurePass 0.1.0 及以后。
> 一句话总结：**你的密码只存在你自己的电脑上。本应用没有账号、没有云端、没有遥测、没有统计。**

## 1. 应用会处理哪些数据

| 数据                                       | 位置                                  | 是否加密                                     | 用途               |
| ------------------------------------------ | ------------------------------------- | -------------------------------------------- | ------------------ |
| 密码库（记录、备注、标签）                 | 数据目录下 `vault.securepass`         | ✅ AES-256-GCM，密钥由主密码经 Argon2id 派生 | 保存你的记录       |
| 上一版密码库副本                           | 同目录 `vault.securepass.bak`         | ✅ 同上                                      | 写入中断时回滚     |
| 界面偏好（主题、语言、强调色、生成器位置） | 同目录 `ui-preferences.json`          | ❌ 明文，但不含任何记录内容                  | 下次启动时保持外观 |
| 窗口位置与大小                             | 同目录 `window-state.json`            | ❌ 明文，只有坐标与尺寸                      | 记住窗口           |
| 运行日志                                   | 同目录 `logs/main.log`（512 KB 轮转） | ❌ 明文，**已脱敏**                          | 排查故障           |

数据目录（默认值）：

- Windows：`%APPDATA%\SecurePass`
- macOS：`~/Library/Application Support/SecurePass`
- Linux：`~/.config/SecurePass`

设置页「关于」区块可以直接打开该目录。

## 2. 日志里不会出现什么

- 不记录主密码、任何记录密码、备注正文或密码库解密后的内容；
- 字段名包含 `password` / `passphrase` / `secret` / `token` / `apiKey` / `dataKey` / `kek` / `dek` 的值一律替换为 `[redacted]`；
- 长度 ≥ 40 的 base64 片段（可能是密钥或密文）替换为 `[redacted]`；
- 异常信息与堆栈走同一套脱敏，堆栈只保留前 2000 字符；
- 只会看到类似 `[ipc] vault:unlock failed: INVALID_MASTER_PASSWORD` 这样的错误码。

日志不会自动上传。反馈问题时由你自行决定是否附上。

## 3. 唯一的联网行为：手动检查更新

- 触发条件：**只有你在「设置 → 关于」点击「检查更新」时**才会发起请求；
- 请求内容：一次 `GET https://api.github.com/repos/<owner>/<repo>/releases/latest`，只带 `Accept`、`X-GitHub-Api-Version` 与 `User-Agent: SecurePass/<版本>`；
- **不上传**任何信息：没有账号标识、没有记录内容、没有设备指纹、没有安装 ID，请求体为空；
- 不使用 Cookie / 本地存储做跟踪；响应只在内存里用于比较版本号，不落盘；
- 失败（离线、超时 8 秒、GitHub 不可达）只会在界面上提示一次，不重试、不排队、不上报；
- 若要完全断网使用：不点这个按钮即可；应用其余功能全部离线可用。

GitHub 作为第三方会按其隐私政策记录访问日志（IP、User-Agent），这属于任何 HTTP 请求的常规行为，本应用无法控制。

## 4. 系统层面的行为（不上传，但会访问本机资源）

- **剪贴板**：复制密码/账号时写入系统剪贴板，按设置的秒数（默认 30 秒）自动清空；锁库时立刻清空，但只清「应用自己复制且仍在剪贴板里的内容」，不会动你后来复制的东西。注意：自动清空**不能**删除系统或第三方剪贴板历史工具已经记录的副本。
- **窗口标题栏颜色**：通过 Electron 的 `titleBarOverlay` 接口同步主题色。
- **系统空闲时间**：读取 `powerMonitor.getSystemIdleTime()` 与窗口焦点状态，用于自动锁定；数值不落盘、不外发。
- **锁屏/休眠事件**：收到系统事件时立即锁定密码库。

以上都在本机完成，不经过网络。

## 5. 不会做的事

- ❌ 不需要注册、不收集邮箱；
- ❌ 不做崩溃上报、不做使用统计、不接入任何分析 SDK；
- ❌ 不读写密码库以外的用户文件（备份/恢复只在你选择的路径上读写）；
- ❌ 不做云端同步、不做「忘记主密码」找回——主密码只在你脑子里。

## 6. 你可以自己验证

1. 断网后使用全部功能（除「检查更新」）；
2. 用抓包工具观察：只有点击「检查更新」时出现一次到 `api.github.com` 的 TLS 连接；
3. 搜索数据目录下的所有文件，确认找不到记录标题、账号、密码的明文与 base64 形态（`docs/TEST-REPORT.zh-CN.md` §5 有实测方法与结论）；
4. 阅读 `src/main/services/log.service.ts`、`src/main/services/update.service.ts`、`src/main/services/clipboard.service.ts` —— 这三个文件就是全部相关逻辑。
