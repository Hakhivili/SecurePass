# 安全说明

## 保护目标

SecurePass 重点防范设备丢失后密码库文件被复制、备份泄露、应用意外展示明文、文件被篡改以及异常
写入导致的数据损坏。

以下情况不在首版防护范围内：

- 操作系统已被恶意软件、内核级后门或键盘记录器控制
- 解锁期间内存被具有足够权限的攻击者读取
- 用户主动导出明文或在外部软件中泄露密码
- 用户忘记主密码

## 加密设计

- 密钥派生：Argon2id，默认 3 次迭代、64 MiB 内存、并行度 4、输出 32 字节。
- 认证加密：AES-256-GCM，96 位随机 IV，128 位认证标签。
- 密钥层级：主密码 → KEK → 解密随机 DEK → 解密/加密密码库。
- 每个密码库独立随机盐；同一次加密不会复用 IV。
- 任何密文或标签被修改都会导致解密失败，不输出未认证内容。

Argon2id 参数可在目标设备上做性能测试后调整，参数与格式版本随文件保存。

## 明文与内存控制

- 主密码、数据密钥、业务密码不写入日志、配置、临时文件或崩溃报告。
- 解锁后明文记录存在于主进程内存中；锁定时释放引用并将可清零的 Buffer 填零。
- JavaScript 字符串无法可靠清零，垃圾回收时机由运行时决定，这是本实现已知限制。
- 复制密码 30 秒后（可配置）仅在剪贴板内容仍为本次复制内容时清空。
- 系统剪贴板历史、输入法记录或第三方剪贴板工具可能保留副本，自动清理不能保证删除这些副本。

## 自动锁定

以下情况会立即或定时锁定：

- 用户点击“锁定”
- 无操作达到配置的自动锁定时间（默认 5 分钟）
- 操作系统锁屏或休眠

锁定后清除界面明文、搜索结果和引用，所有需要解锁的资料访问返回 `VAULT_LOCKED`。

## 失败处理

- 回复错误主密码只返回统一的解密失败错误，不区分“密码错误”和“文件损坏”。
- 错误的恢复文件不会覆盖当前密码库。
- 恢复前先复制当前库为 `pre-restore-<时间>.bak` 加密副本。
- 密码库写入使用原子替换，磁盘空间不足或进程中断时保留旧版本。
- 首版限制同一密码库只允许一个进程写入，通过锁文件实现。

## 备份语义

- 备份包含格式版本、KDF 参数、封装后的数据密钥和完整密文。
- 备份使用导出时的主密码；修改主密码不会改变旧备份的解锁密码。
- 不提供默认明文导出。
- 备份文件本身是密文，请与设备分开保管，避免同时丢失设备与备份。

## 依赖与密码算法

- 不自行实现密码算法。
- Argon2id 使用持续维护的 `hash-wasm`；对称加密使用 Node.js `crypto` 内置实现。
- 第三方依赖应在发布前生成清单、许可证信息和已知漏洞报告。

## 报告安全问题

请不要在公开 Issue 中披露未修复的漏洞细节。请提供复现步骤、影响范围和建议修复方向，
维护者确认后再协调公开时间。
